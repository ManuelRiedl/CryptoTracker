
# CryptoTracker

A Flutter app for tracking real-time cryptocurrency prices, viewing historical price charts, and searching across a wide range of coins.

## Technology Stack

* **Frontend:** Flutter (Dart)
* **Data:** REST API via HTTP
* **State Management:** Provider
* **Charts:** fl_chart

## Functionality

### Live Price Overview
The app fetches and displays up-to-date prices for a wide range of cryptocurrencies, including percentage changes and market data.
